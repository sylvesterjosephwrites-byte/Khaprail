## Session discipline

- Don't start a new batch with less than ~20% context/budget remaining if it can be avoided — better to stop cleanly at a batch boundary and log it than to leave a batch half-done with no note.
- If a batch turns out bigger than expected, split it and log the split in `00-PROGRESS.md` rather than silently under-delivering.
